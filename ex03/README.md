# Discovery Web Piscine

## Project Overview

This project covers the fundamentals of Linux, Git, GitHub, and secure Git authentication.

## Why Git Makes Development Easier

Git makes development easier by keeping track of changes made to files over time. It allows developers to save different versions of their work, so they can review changes or return to an earlier version if needed.

Git also helps safeguard code by maintaining a history of commits. Each commit records a specific change, making it easier to understand what was changed and when.

For team collaboration, Git allows multiple developers to work on the same project while keeping track of their changes. GitHub provides a remote place to store and share the project, making collaboration and code management easier.

## Git Workflow

The basic Git workflow used in this project is:

1. Edit files
2. Add changes with `git add`
3. Commit changes with `git commit`
4. Push changes to GitHub with `git push`

## Authentication

SSH authentication can be used to securely connect the local Git repository to GitHub without entering a password for every push.
